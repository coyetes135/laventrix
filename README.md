# Laventrix — Servicio de Lavandería Industrial B2B

Landing page del proyecto Laventrix: servicio B2B de lavandería industrial con retiro, lavado, identificación y devolución de prendas.

## Tecnologías
- HTML5, CSS3, JavaScript (vanilla)
- PWA (manifest + service worker)

## Uso local
Abre `index.html` en el navegador.

## Publicación (GitHub Pages)
Settings → Pages → Source: `main` / root → Save.
URL: https://coyetes135.github.io/laventrix/
